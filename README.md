# Network_Walks-Virtual_Machine_Setup-KALI-LINUX - CYBERSECURITY LAB (B084C)
--Setting up an isolated virtual lab for ethical hacking and cybersecurity practice--

<b>Project Overview</b>
This project focuses on setting up a virtual cybersecurity lab where different projects related to ethical hacking and penetration testing can be done. KALI LINUX is set up and configured on a private network (10.0.0.0/24). Thus, the ultimate purpose of the lab is to create a controlled environment where cybersecurity concepts like network mapping, port scanning, recon and several others can be practically implied.
